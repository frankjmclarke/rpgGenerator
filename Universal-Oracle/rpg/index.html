RPG Oracle (Gamemaster's Apprentice style)

This deck is for solo or GMless RPG play. It answers questions; you interpret. Pick the genre that matches your campaign tone — switching genres only swaps the word lists, not the mechanics.

Yes / No

Three odds tiers. Probably = +6 to the chaos threshold (more YES). Unsure = ±0. Probably not = −6 (more NO). A reference number 1–23 is drawn vs the threshold. Critical rolls (11 or 22) ≤ chaos turn the answer into YES! or NO! — read it as decisive.

Random Event

Verb + Adjective + Noun. Read it as a sentence — "Betray // Hidden // Promise". Apply it to whoever is on stage, or treat it as off-stage news.

NPC

Reaction = how this NPC feels right now (Hostile / Wary / Neutral / Friendly / Helpful). Virtue + Vice = what they want and what they fear, the deeper layer.

Scene

Catalyst = a curated inciting incident to kick off a scene. Sensory = four lines (hear / see / feel / smell) to ground the location.

Generators

3 names for instant NPCs. Location for instant places. Both pulled from the active genre pack.

Combat

This deck is built for social/scene play. When a fight breaks out, click Combat → Skirmish to hand off to the dedicated battlefield AI deck.
